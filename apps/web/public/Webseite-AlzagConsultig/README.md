# Webseite Alzag Consulting

## Lokal starten

1. In das Projektverzeichnis wechseln:
   ```bash
   cd /workspaces/webseitealzagconsulting
   ```
2. Lokalen Server starten:
   ```bash
   ./start-local.sh
   ```
3. Im Browser öffnen:
   ```text
   http://localhost:8000/index.html
   ```

## Anderen Port verwenden

```bash
./start-local.sh 8080
```

Dann im Browser:

```text
http://localhost:8080/index.html
```

## Server stoppen

Im Terminal `Ctrl + C` drücken.
